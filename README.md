# KubeNet

An Omarchy-inspired network dashboard for KDE Plasma 5.27.

KubeNet is intended to provide a compact, information-rich network panel for KDE Plasma, using NetworkManager for network state and controls.

## Project status

🚧 Early development — initial Plasma 5.27 widget skeleton.

The project is being developed and tested first on:

- Kubuntu 24.04 LTS
- KDE Plasma 5.27
- Qt 5.15
- NetworkManager 1.46+

## Planned features

- Current Wi-Fi/network connection
- Signal strength and Wi-Fi details
- IP address and gateway
- Current frequency, channel, and link speed
- Live download/upload throughput
- Throughput graph
- Ping, jitter, and packet-loss monitoring
- Latency history graph
- VPN status
- DNS provider selection
- Available and known Wi-Fi networks
- Network connection controls
- Internet speed test and result history

## Development

KubeNet is being developed as a KDE Plasma 5 Plasmoid. The first milestone is a user-installable widget; networking functionality will be added incrementally.
